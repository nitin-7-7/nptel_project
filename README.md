# 🌱 NPTEL Environmental Engineering Quiz

An interactive and beautifully designed quiz platform for practicing **NPTEL Environmental Engineering & Science** questions (Assignments 1–12).

---

## 🚀 Features

✨ Clean & Modern UI  
🎯 Covers all assignments (1–12)  
📊 Real-time progress tracking  
📌 Question Navigator (jump to any question)  
🔀 Shuffle options  
✅ Instant answer feedback  
📈 Final score analysis (Correct / Wrong / Skipped)  
🔁 Retry wrong questions  
🎛 Filter questions by assignment  

---

## 🖥️ Tech Stack

- HTML5  
- CSS3 (Custom styling + gradients + responsive UI)  
- Vanilla JavaScript (No frameworks, pure logic)

## 🎮 How to Use

- Select answers → get instant feedback  
- Enable/disable:
  - ✔ Show answers instantly  
  - 🔀 Shuffle options  
- Use **Submit All** to get final score  
- Retry wrong questions for better practice
